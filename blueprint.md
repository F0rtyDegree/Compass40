# проект Compass40

## 1. О проекте

**Название:** Compass40 (в pubspec — `compass40`).
**Платформа:** Android, Flutter (Dart SDK ^3.9.0).
**Назначение:** компас с расширенными функциями. Магнитный и GPS-компас, карта с привязкой по якорям, ведение на цель, запись трека в GPX.
**Язык общения:** русский.
**Разработчик:** один, сам пользователь.

## 3. Архитектура

**Слои:**

```
lib/
  main.dart                  — точка входа, permission, background service
  app/my_app.dart            — MaterialApp
  screens/                   — экраны (StatefulWidget)
  controllers/               — логика экранов
  services/                  — сервисы, доступ к железу и данным
  models/                    — модели данных
  transforms/                — математика преобразований карты
  widgets/                   — переиспользуемые виджеты
  utils/                     — утилиты и константы
```

**Ключевые синглтоны** (осознанно, не рефакторить):
- `GpsManager` — раздача GPS-данных через broadcast stream. Управляется вручную `start(intervalSeconds)` / `stop()` из `HomeLogic`.
- `SensorService` — доступ к GPS-платформе и настройкам.
- `CompassService` — магнитный компас (собственная реализация на Dart).
- `GpsCompassService` — GPS-компас.
- `TrackRecorder` — запись точек трека в CSV.
- `MapScreenController` — мост интентов (Tasker и т.п.) к активному экрану карты.

**Поток данных GPS:**
```
Android LocationManager
  → GpsInfoPlugin (Kotlin)
  → EventChannel
  → SensorService.subscribeToGps
  → GpsManager.gpsStream (broadcast)
  → HomeLogic, GpsCompassService, TrackRecorder
```

**Компас:**
Магнитный — свой. `CompassService._tryEmit` считает курс по формулам `E = M × G`, `N = G × E`, `heading = atan2(ey, ny)`. Есть калибровка hard iron (офсеты `cx/cy/cz`), медианная фильтрация, сглаживание EMA через cos/sin.

## 6. Отложено с комментариями в коде

Не переделывать без явной необходимости. В каждом месте есть комментарий с обоснованием.

1. **Жёсткие пути Android** (`AppConstants.externalDownloadDir`). Работает у текущего пользователя. Переделать на `path_provider` — когда появятся проблемы.
2. **`Future.delayed(300)` в `main.dart`** перед уведомлением. Эмпирическая пауза.
3. **`Future.delayed(1s)` в `MapCalibrationService.toggleAnchorPinned`** — не отменяется. Риск низкий.
4. **`saveProject` без `await` в `MapScreenLogic.dispose`** — вторичная страховка, критичное сохраняется раньше.
5. **Множественные синглтоны.** Для интеграционных тестов — отдельное mock-приложение.
6. **Смешение `ValueNotifier` и `setState`** в `HomeState`, `MapScreenState`.
7. **`help_viewer_screen` без кэша** markdown.
8. **`Dismissible` с прозрачным фоном** в `GpsSection`.

## 10. Известные особенности

- В GPS-режиме компаса магнитное склонение взаимно компенсируется в `followMode`: `magneticBearing` и `mapRotation` оба зависят от склонения. Это **корректно**. В магнитном режиме склонение влияет на ориентацию карты.
- `computeResetRotation` не использует `declinationRad` — параметр удалён в 7.1.0.
- `MapCalibrationService._checkAndApplyManualSet` вызывается с задержкой 1 секунда после клика по якорю (проверка коллинеарности).
